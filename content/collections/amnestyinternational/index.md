# Amnesty International Anti-Trans Reports Archive

This source content folder is reserved for curated long-form copy and per-document metadata for `/amnestyinternational`.

Do not add real downloadable documents until each file has:

- Confirmed title.
- Original publisher.
- Original URL or source citation.
- Archived original URL when available.
- Publication date when known.
- Removal/unavailability evidence.
- SHA-256 checksum.
- File size.
- Primary download URL.
- At least one mirror when possible.
- Content warning and editorial context.
